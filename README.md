# ComplyOS - Product case study

One-page interactive case study of ComplyOS, a unified compliance operations and financial crime intelligence platform.

**Live site:** https://fahadhaxan.github.io/complyos/

Covers problem discovery, product vision and solution design (four domains), system architecture (multi-tenant application and data, control rule book, financial crime monitoring pipeline, AI and document intelligence), product development and implementation, differentiation and a capability snapshot, and the roadmap.

Static site - no framework, no build step. Poppins is embedded, so the page works offline.
